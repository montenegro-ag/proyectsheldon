# proyectsheldon
Repositorio para la Actividad 1: Juego Pintando (Paint) de Python.

## Contenido
Juego de dibujo con Turtle Graphics que permite crear líneas, cuadrados, 
círculos, rectángulos y triángulos en distintos colores.

## Cambios realizados
- Se agregó el color amarillo a la paleta disponible (tecla Y)
- Se implementó la función circle para dibujar círculos
- Se implementó la función rectangle para dibujar rectángulos
- Se implementó la función triangle para dibujar triángulos
